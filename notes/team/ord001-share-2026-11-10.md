# ORD001 组内共享上线记录

用户选择使用 Surge，授权将已配置的真实模型提供给组员使用。Surge 仅提供固定静态入口，完整网页和 Python / LangGraph 后端继续运行在演示 Mac 上，通过 Cloudflare Quick Tunnel 的 HTTPS 通道访问。公开入口已经实际发布及验证，不等同于把 Python 部署到 Surge，也不是电脑关机后仍可使用的独立云服务。

| 用途 | 公开地址 |
|---|---|

| 商家固定入口 | https://ord001-group24.surge.sh/review |

Surge 页面会自动跳转到当前临时后端。无 JavaScript 时仍可点击入口。`/review` 使用 `200.html` 保留商家路由。页面设为不索引，无外部字体、脚本或图片请求。

小组访问口令由演示负责人单独提供，进入后选择模拟身份 U001 / U002 / R001。口令、Surge 登录资料与发布令牌、DeepSeek 密钥均不进入仓库、网页、URL、截图或交付包。共享入口的访问口令与 Surge 登录密码无关。

本机已打开桌面私有访问说明，文件权限为 0600。该文件供负责人自行转发组员，没有通过消息工具替用户发给任何组员。

## 结构与保护

```text
组员 → Surge 固定入口 → HTTPS 临时通道
                         → 本机 127.0.0.1:8028 访问网关
                         → 原 127.0.0.1:8024 网页与真实模型服务
                         → DeepSeek 官方 API
```

新增 [ord001_share.py](../../examples/ord001/ord001_share.py)，没有修改原网页 API、业务图、资格规则或数据库：

- 所有业务页面、静态文件和 API 都要求有效共享会话；未授权 API 返回 401。只有访问口令页公开。
- HMAC 签名会话八小时有效，Cookie 使用 Secure / HttpOnly / SameSite=Lax；不把口令直接存在浏览器 Cookie 中。
- 精确校验公开 Host 与同源 HTTPS Origin；校验后才将 Host / Origin 改写为本机上游地址。原服务仍保留 TrustedHost 与 JSON 同源保护。
- 不合并共享 HTTP 客户端中的登录 Cookie。每次请求只使用相应浏览器传来的 Cookie，防止不同组员串号。
- 口令尝试全组每分钟最多 30 次；聊天请求全组每分钟最多 20 次、最多两条同时进入后端；超限明确拒绝。请求体上限 16 KiB。
- 共享入口禁止调用清空演示库的接口，包括尾斜线和编码变体。本机原入口仍可由演示负责人操作。
- 模型密钥只由原后端私有配置读取。浏览器只访问 Surge 与临时网页域名，不直接请求模型供应商。
- 本机 8024 服务与 SQLite 未重启、未重置；2024 Studio 未操作。公网验证后数据库仍为 1 张工单、1 条处理事件。

小组口令适用于课程共享。进入后仍可选择模拟身份，未实现生产账号认证或顾客、商家注册系统。没有设置每日费用预算，也没有宣称完成生产安全或负载验收。

## 运行与恢复边界

- 保持演示电脑、8024 后端、8028 访问网关与 Cloudflare 通道持续运行。关机、合盖睡眠、网络断开或进程停止均会使后端不可用。
- Surge 固定域名保留，但 Quick Tunnel 每次重新创建都会换地址。恢复时需更新 `share/entry.html` 中 `__LIVE_ORIGIN__` 的发布替换值，生成入口的 `index.html` / `200.html` 后重新部署到原 Surge 域名；不能只重新打开旧 Surge 页面。
- 原始模板在 [share/entry.html](../../examples/ord001/share/entry.html)，访问口令页面在 [share/access.html](../../examples/ord001/share/access.html)。只把生成的入口 HTML、robots.txt 与 CNAME 放进 Surge 发布目录，禁止对整个项目目录执行静态发布。
- 本机工具：Surge CLI 0.56.0；cloudflared 2026.10.7，官方发布归档 SHA256 校验通过。安装文件、令牌、私有访问文件和运行库均在 Git 工作目录外。
- 组员不必获得提供商密钥；所有模型费用由当前演示账户承担。历史真实模型交付包仍为无密钥本机包，不随本次共享自动更新。
