# IS5542 课程项目要求

本项目是 IS5542 的 GenAI 应用小组作业。组内正在做的范围、技术方向、分工和评测方案见[当前方案与进度](current-plan.md)。

## 课程交付

此前核对的 Canvas 项目公告记录 **2026 年 11 月 28 日交录制视频和 slides，无现场演示**。10 月 26 日的互评说明记录项目合计占课程成绩 30%，团队展示占 20%，同伴互评占 10%。提交入口、当天时刻和互评表状态以 Canvas 后续更新为准。 [项目公告](https://canvas.cityu.edu.hk/courses/71410/discussion_topics/632216) · [互评说明](https://canvas.cityu.edu.hk/courses/71410/discussion_topics/642339)

| 展示环节 | 交代什么 |
|---|---|
| 业务问题 | 谁受影响，现有处理方式有什么局限，问题规模的依据是什么。 |
| GenAI 方案 | 工作流、模型选择理由、数据来源，以及实际能跑的 Agent 演示。 |
| 结果与价值 | 对照已有产品或基线，报告正确性、安全、效率与成本，并解释可支持的业务结论。 |
| 后续工作 | 说明上线或扩大范围还需要什么数据、接入与验证。 |

课程项目模板第 5–8 页的 2／7／4／2 分钟用于展示结构安排。课堂转录约 19:03 处强调要有可运行的 Agent 和 Demo。本组按可运行方案准备。

## 怎样用到本组工作

先读[当前方案与进度](current-plan.md)里的项目目标、订单流程和两条对照。市场产品部分由调研组按统一场景留证。团队首版先完成可复跑的订单、资格判断和审批流程，再用同案验证和运行证据写展示结论。

往期场景选择、拟用模型和规模建议见[历史计划](外卖考场设计与分工计划.md)及[会议决策](团队会议与决策.md)。当前交件和建议日期见[首页首轮分工](../README.md#首轮实名分工)。
